Reading List / 视频学习

一边看，一边理解

原文留在眼前，译文跟着播放位置走。

  1. 启动本机服务后，点击视频下方的“设置”，输入终端中的配对码。
  2. 点击“获取字幕”；也可以下载测试 VTT后点击“导入字幕”。
  3. 点击“开始翻译”，然后播放或点击字幕跳转。
  4. 用“复制当前双语”将带时间链接的片段粘贴到笔记中。

使用自己的 API

在本机 .env 中设置 OPENAI_BASE_URL、OPENAI_API_KEY、OPENAI_MODEL，再重启服务。支持兼容 Chat Completions 的 API，包括本机模型。

首次请求可能出现浏览器“本地网络访问”提示。画面内字幕在 YouTube 原生全屏 / 画中画内不可见；普通 Roam 视频布局支持。
