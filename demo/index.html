Reading List / 视频学习

一边看，一边理解

原文留在眼前，译文跟着播放位置走。

  1. 用 npm start 启动本机原字幕服务，然后点视频右上角“双语”。默认不需要 API Key 或配对码。
  2. YouTube 自己显示中文自动翻译，插件只同步叠加英文。请保留原生 CC。
  3. 关闭“双语”会隐藏英文叠层，保留 YouTube 自带中文。旧的样式预览已移除。
  4. 需要文件导入时，可下载测试 VTT，再从弹出设置中导入。下方不创建字幕面板。

自定义 API 只是可选项

默认直接用 YouTube 自带翻译。只有主动选择“自定义 API”模式时才需要在本机 .env 填写接口和模型；演示服务仅用于这个可选模式的开发回归。

首次请求可能出现浏览器“本地网络访问”提示。画面内字幕在 YouTube 原生全屏 / 画中画内不可见；普通 Roam 视频布局支持。
