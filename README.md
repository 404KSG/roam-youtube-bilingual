# Roam 紧凑双语字幕

> **0.5.0-beta.1 开发候选版，尚未切换到安装渠道。** 离线代码与布局回归已完成，真实桌面验收仍待完成；暂未更新线上 Draft shorthand。当前已发布、可用的 Draft 仍为 0.4.0-beta.1。

## 这版的界面

- 双语入口是**视频下方原生工具栏里的一个图标**，不再占用画面右上角。
- 字幕只有**上下两行**：上面英文一行，下面译文一行。原字幕中的换行会接起来，横向展开。
- 两行紧挨着，**共用一个不透明背景**，不保留两块分离的字幕框。
- 设置只保留**开启/关闭、译文语言、字号**。自定义 API、模型、密钥、配对码、服务地址、导入和其他高级表单已移除。
- 目标语言列表来自当前 YouTube 视频的字幕元数据，包含该视频可用的日语、中文、法语等选项，不依赖写死的少量语言。
- 字号同时作用于两行。长句先用足视频宽度；仍放不下时会缩小，不拆成四行，也不省略文字。

## 翻译和排版是分开的

翻译仍由 **YouTube 自带自动翻译**完成，不调用 AI 翻译 API。

为了把译文与英文真正放进同一个背景，候选版使用本机只读桥提取 YouTube **已经显示出来的译文**，再与英文原字幕一起排版：

```text
YouTube 原生自动翻译 → 已显示的译文
                         │ 本机只读提取
英文原字幕 + 播放时间 ────┤
                         ▼
              英文一行 + 译文一行
                 同一个紧凑背景
```

字幕背景会覆盖原来的原生字幕区域，但不会关闭原生 CC，因为它仍负责提供真实译文。关闭双语、读取失败或字幕过期时会移除遮罩，让原生字幕恢复可见，不使用样例或假译文填充。

## 当前支持范围与隐私

这个同框实现目前针对 **macOS 的 Roam Research 桌面版**。需要已安装的 Node.js 22.10+、yt-dlp，以及已运行并已有辅助功能权限的 CuaDriver。本项目不会自动安装软件、申请/更改权限、解锁屏幕、启动录制或操作其他应用。

开启双语时，本机桥会临时读取指定 Roam 窗口的无障碍结构，只提取与**当前视频标题和位置相符的 YouTube 字幕节点**。其他节点会在本机内丢弃；无障碍树、笔记、窗口标题和截图不会返回给插件或写入磁盘。它不通过图谱 API 读取或修改笔记。

- 字幕读取只允许当前登录 OS 用户、且来自 Roam 桌面进程的本机连接；通过 socket 所属进程校验，并继续检查 Host、Origin、视频 ID、支持的语言和视频范围。
- 不接受调用方指定任意 PID、窗口或工具动作。
- 读取组件只使用现有只读能力，不截图、不录制；发现工具处于录制状态时会停止读取。
- 关闭双语、打开设置、视频离开可视区域或页面隐藏时不读取字幕。
- 锁屏或字幕树不可用时不绕过限制，也不显示旧译文。

## 使用流程（真实验收通过后）

1. 双击 `start.command`，或在项目目录执行 `npm start`。不用配置任何 API。
2. 在 Roam 视频下方的图标栏点击新增的双语图标。
3. 开启双语，选择目标语言，调整字号，点“完成”。

原 shorthand 保留：

```text
404KSG+roam-youtube-bilingual+1509
```

**候选版尚未通过真实桌面验收，不要把当前 shorthand 当成已经包含本版的新界面。** Draft PR 不会被合并或正式上架。已有 0.4.0 的工作版本和它的服务保持不变，验收完成后再统一更新插件与本机服务。

## 设置说明

- 原文固定为英文，位于第一行。
- 译文语言由当前视频实际提供的语言列表决定。
- 字号范围 12–36 px，表示首选字号；超长句会按可用宽度适配。
- 切换目标语言不会重新下载英文；只切换 YouTube 译文轨道。
- 设置是即时生效的，“完成”关闭设置窗口。

需要保留双语的全屏，可从 Roam 命令面板运行“**YouTube 双语字幕：双语全屏**”。YouTube 自带 iframe 全屏/PiP 不包含插件层。

## 本机服务

默认地址为 `http://127.0.0.1:17321`。不需要 `.env`，也没有开机启动或定时任务。若已有 `.env`，仅读取 `PORT`、`YT_DLP_PATH`、`CUA_DRIVER_PATH` 三个运行参数，不读取旧的 API 配置。

语言列表和英文原字幕可以通过只读接口获取；涉及桌面字幕的接口额外验证连接的 OS 用户。所有自定义 AI 翻译接口已删除。

## 开发

```bash
./build.sh
```

- `src/extension.mjs`：底部图标、精简设置、原文与译文同步排版。
- `src/surface.mjs`：视频叠层和双语全屏。
- `server/video-info.mjs`：当前视频的英文轨道与可用语言。
- `server/caption-reader.mjs`：严格限定的本机只读字幕提取。
- `test/unified-fixture.html`：纯本地测试页面，无真实视频内容。

本地截图和临时日志只在被 Git 排除的 `artifacts/` 中。停用扩展会移除自己的图标、遮罩和样式，保留原生视频及工具栏图标。
