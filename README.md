# Roam 视频内双语字幕

> **0.3.0-beta.1 · Draft 测试版，未正式上架。**
>
> 这是一个画面内字幕插件，不是视频下方的转录面板。原文在上、译文在下，直接叠在 YouTube 视频画面底部，跟随播放、暂停和进度跳转。

## 你会看到什么

- 视频右上方只有一个小“**双语**”开关和“**⋯**”设置按钮。
- 开启后自动获取原字幕，按播放位置调用你的 API，原文与译文同时显示在画面里。
- 不在视频下方创建卡片、字幕列表或工具栏，不改变视频大小，不写入笔记。
- 字幕大小、垂直位置、语言、时间偏移和文件导入都放在点击后才出现的设置中。
- UI 使用 Shadow DOM 隔离，避免 Roam / 主题样式影响字幕与按钮。
- 关闭双语立即隐藏字幕并取消尚未完成的请求；打开插件本身不会调用翻译 API。

**这是对 0.2.x 方向的修正。旧版下方常驻面板、字幕列表和导出入口已从界面移除。**


已经安装同一 shorthand 的用户，点击该行的重新加载按钮即可，不要重复添加。当前版本在“⋯”设置顶部显示 `0.3.0-beta.1`。

[Draft PR #1509](https://github.com/Roam-Research/roam-depot/pull/1509) 仅用于预览测试；没有合并、正式上架或创建 Release。源码的默认分支仍沿用早期预览分支名，实际版本以 `package.json` 和插件设置为准。

也可以用开发者模式加载包含 `extension.js` 的项目文件夹，或把 `dist/roam-youtube-bilingual.js` 的完整内容放进启用的 `roam/js` JavaScript 代码块。只使用一种加载方式。

## 先看显示效果，不需要 API

点击视频内“**⋯**” → **预览画面内双语效果（不调用 API）**。

两行示例字幕会在画面内显示 8 秒，明确标注“**样式预览 · 非视频字幕**”。它用于确认位置、字号和视觉效果，不代表已经调用真实翻译服务。点击“预览”小开关可提前关闭。

## 接入自己的翻译 API

### 为什么还需要本机服务

Roam 页面不能跨域读取 YouTube iframe 内部；[YouTube IFrame API](https://developers.google.com/youtube/iframe_api_reference) 也不提供完整字幕文本。因此本插件由两部分组成：

```text
YouTube 播放时间 → Roam 视频内双语叠层
                         │
                         ▼
                  本机服务 127.0.0.1
                  ├─ yt-dlp 获取原字幕
                  └─ 你配置的翻译 API
```

**shorthand 安装界面部分，不会自动启动本机服务。** API Key 留在本机，不写进 Roam 图谱。翻译会把请求范围内的原字幕发送到你选择的供应商；可使用本机模型避免远程发送。

### 1. 启动本机服务

需要 Node.js **22.10+**。自动获取 YouTube 字幕还需已安装的 `yt-dlp`；导入 SRT / VTT 不需要它。无 npm 运行依赖，不用执行 `npm install`。

```bash
cd /path/to/roam-youtube-bilingual
cp -n .env.example .env
chmod 600 .env
```

在本机 `.env` 中填写：

```dotenv
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_API_KEY=你的APIKey
OPENAI_MODEL=供应商实际支持的模型名
```

支持 **OpenAI-compatible Chat Completions** 接口。根地址会追加 `/chat/completions`，也可填写完整路径。远程 API 要求 HTTPS；本机兼容模型可用 HTTP，例如 `http://127.0.0.1:11434/v1`，本机模型可不填 Key。

然后运行 `npm start`，或在 Mac 双击 `start.command`。终端会显示地址和配对码；保持终端打开。修改 `.env` 后重启服务。没有安装开机启动或定时任务。

原生 Claude Messages / Gemini GenerateContent 协议需要兼容网关，本版没有直接适配它们。

### 2. 在视频内连接

1. 点击视频右上方“**⋯**”。
2. 填写本机服务地址和终端中的**配对码**，不是 API Key。
3. 原字幕语言默认 `en`，目标语言默认 `zh-CN`。轨道代码需匹配视频，例如部分视频使用 `en-US`。
4. 点击 **检查连接**，或直接 **保存并开启双语**。
5. 播放视频，原文与译文在画面内同步出现。以后用“**双语**”小开关启停。

每次只允许一个视频自动翻译。只处理当前播放位置前方约 90 秒内的字幕，每批最多 24 条，不默认翻译整条长视频。首次译文会受供应商延迟影响。

### 3. 可选调校

- **字幕大小**：0.75–1.6 倍，默认 1。
- **距底部比例**：0.02–0.25，默认 0.08；可调整以避开画面内容。
- 展开 **字幕文件、同步与全屏** 可导入 SRT / VTT / JSON3、重新获取原字幕或调整时间偏移。正数使字幕延后。
- **如果原生 CC 也开着，请关闭 YouTube 自带字幕，避免重复。** 本插件不会擅自修改你的 YouTube 字幕偏好。

## 全屏边界

原生 Roam 视频容器支持：**⋯ → 字幕文件、同步与全屏 → 双语全屏**。它将视频与插件字幕一起进入全屏，退出后恢复原容器样式。

**YouTube 自带的全屏按钮和原生画中画不包含 Roam 外层字幕。** 浏览器扩展可以注入 YouTube 子框架，纯 Roam 插件不能；两者不是完全等价的权限环境。普通没有原生 Roam 视频容器的 HTML iframe 使用贴合画面的定位叠层，可能不提供“双语全屏”。

## 演示与验证

```bash
npm run demo
```

- `/demo`：真实嵌入播放器配合 5 条预置示例字幕/译文，明确标注演示状态，不调用付费 API。
- `/roam-layout`：复刻 Roam 原生剧场的类名、比例容器和工具栏，用于检查字幕是否完全位于画面内、是否改变原布局。
- 正式 `npm start` 下，这些页面的字幕与翻译请求使用真实服务配置；“样式预览”始终不调用 API。

本版验收重点不是下面的卡片是否显示，而是：**没有下方插件面板、双语文字位于 iframe 画面边界内、开关可点、进度变化时同步换句、原视频布局不变。**

测试包括 Node 回归、`test/overlay-browser.mjs` 的画面内交互/生命周期检查、多个视口、真实 YouTube 播放时间反馈及双语全屏。真实模型的质量、延迟和费用仍需用户配置 API 后验收；预置译文和样式预览不作为真实翻译成功证据。

## 限制与隐私

- 支持 YouTube `/embed/` iframe，不给普通文本链接创建播放器。
- yt-dlp 可能遇到限流、地区限制、登录要求或 YouTube 改版；失败时可导入字幕。不绕过会员、付费或登录限制。
- 无字幕视频不自动语音转写，直播实时字幕未支持。
- 首次开启可能重新加载缺少 `enablejsapi=1` 的 iframe 一次，以连接播放时间。
- 时间同步依赖 YouTube iframe 消息协议，已隔离为适配器，但不是官方保证稳定的全文字幕接口。
- 字幕导入最多 5 MB / 20000 条，单条原文最多 5500 字符。极长句子在小画面中会被截断，可放大视频或减小字号。
- 连接信息仅保留在当前窗口会话；字幕/译文只缓存在内存中，刷新会丢失。
- 不自动读写笔记、不做遥测、不上传图谱内容。本机服务只监听 127.0.0.1；本地网络权限提示需用户自行处理。
- 暂停/关闭会阻止后续请求，但已发给供应商的请求可能已计费。

## 开发与卸载

```bash
./build.sh  # 构建、语法检查、Node 测试
```

- `src/extension.mjs`：画面内状态、双语开关、弹出设置与按需翻译。
- `src/surface.mjs`：贴合播放器的叠层、可视区域判断和双语全屏。
- `src/clock.mjs`：播放时钟与跳转同步。
- `src/core.mjs`：字幕解析、时间查找、译文编号校验。
- `server/`：本机字幕获取与兼容 API 调用。
- `test/overlay-browser.mjs`：隔离的原生布局验收，禁止在用户图谱中运行。

停用 Depot 开发扩展即可移除叠层。roam/js 版本可调用 `window.roamYouTubeBilingual?.onunload()`。停止服务终端可结束本机进程。测试日志和私有截图位于被 Git 排除的 `artifacts/`，不上传仓库。

本项目是原创实现，仅参考双语视频观看的交互思路，不复制第三方翻译插件的代码或品牌素材。
